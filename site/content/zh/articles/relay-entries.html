中转入口:让用户经另一台机器连进来

出口服务器的线路很好,可用户到它的那一段不行:绕路、丢包,或者那个 IP 在用户那边干脆连不上。常见的办法是在中间放一台用户连得顺的机器。m-ui 里这叫中转入口 —— 这一篇讲它怎么工作,以及它最容易让人摸不着头脑的那个毛病。

两种「经另一台机器」

m-ui 里有两种办法让流量多过一台机器,它们不是一回事:

  • 把线路加为上游(链式代理):中转机上也跑一条线路,它解密用户的流量,再作为客户端连出口。两段各是各的连接,中转机要跑协议、要有证书,多一轮加解密。
  • 中转入口:中转机只搬字节。用户和出口之间还是那一条加密连接,中转机看不到内容,也不需要懂这个协议。TCP、UDP 都能转,所以 Hysteria2、TUIC 也行。

大多数时候要的是后一种:便宜、省事、少一半加解密。数据走向是「用户 → 中转 → 出口(这条线路的服务器)→ 网站」。

怎么加

编辑线路,展开中转入口,点「添加中转入口」。每一条读起来是一句话:用户连哪台中转的哪个端口 → 转给哪台出口。

  • 选集群里的另一台服务器当中转:转发由面板在那台上自动做,端口自动挑一个那台空着的。那台的防火墙(云厂商的安全组)要放行这个端口 —— Hysteria2 / TUIC 是 UDP,Shadowsocks 是 TCP 和 UDP,其余是 TCP。
  • 选「别处的中转(填地址)」:你自己用 realm、iptables 搭的,或者买来的中转。填它的地址和端口,页面上会写清要在中转上把哪个端口、什么流量转到哪里。

保存之后,订阅里每个入口多出一个带 ⇄ 的节点,和直连节点并排,客户端自己测速挑快的。只想让用户走中转,勾上「订阅里只给中转入口,不给出口服务器的直连节点」。每个中转节点在节点设置里可以单独设倍率、限速和容量。

转到出口的哪个地址

集群中转默认转到出口的公网 IP。出口是双栈的话,走 IPv4 还是 IPv6?v0.8.1 起的规则是:

  • 跟这条线路在出口那台用的 IP 版本走 —— 在「部署到服务器」里给那台选了 IPv6(没选就看那台服务器自己的设置),中转也转到它的 IPv6;
  • 前提是中转机自己有 IPv6,没有就还走 IPv4;
  • Hysteria2、TUIC 的线路,中转机自己在订阅里是按 IPv6 给的,也先走 IPv6。

想换,点括号里的地址直接填:换成另一个 IP 版本,或者两台内网互通时填内网地址。

Hysteria2 / TUIC 经中转「连得上但没网」

这是中转入口最常见的一类反馈:TCP 的线路(VLESS、Trojan、AnyTLS)经同一台中转一切正常,Hysteria2 却连上了打不开网页,而直连出口又是好的。

原因多半在中转到出口的那一段带不动大的 UDP 包。Hysteria2 和 TUIC 跑在 QUIC 上,QUIC 的包不允许在路上分片,包多大是客户端和出口两头定的;中转只搬字节,改不了。这一段要是运营商 NAT 出来的 IPv4、或者隧道出来的 IPv6,大一点的 UDP 包常常过不去 —— 小包过得去,所以看着像是「连上了」。TCP 没事,是因为 TCP 两头会按路径自己把包缩小。

办法,按顺序试:

  1. 点括号里的地址,换成出口的另一个 IP 版本(IPv4 换 IPv6,或反过来)。中转机的 IPv4 出口是 NAT、IPv6 是原生的,这种机器上换成 IPv6 往往立刻就好。
  2. 还不行,这条线路改用把线路加为上游:那种是中转机解密后重新发,两段各走各的,包的大小各自协商。

以前这里有个坑:线路在出口那台明明选了 IPv6,中转却仍然转到 IPv4。v0.8.1 起中转跟着线路的选择走。

设备数怎么算

用户经中转连进来时,出口看到的来源是中转机的地址,不是用户的设备。如果把它当成一台设备,限 1 台的用户本人直连在线时再经中转连,就会被当成第二台拒掉;几个用户共用一台中转,也全都「来自同一个 IP」。

所以 v0.8.1 起,经中转入口进来的连接不占用户的设备名额,也不占代理的设备池;在线 IP 里照常列出来,标着是哪台中转。反过来,设备数限制也管不到走中转的连接 —— 要限一个中转节点上的人数,用节点设置里的用户容量。

出口认不出来的中转(经内网转过来的、进出不是同一个 IP 的、地址填的是域名的),要在那个节点的出口看到的来源 IP里填上,否则仍按一台设备算。

几个小坑

  • 中转节点不带端口跳跃。
  • 用户的用量照常按出口服务器的倍率计。服务器自己设了流量额度的,经它中转的流量也算进它的额度 —— 中转和出口两台各算各自真实经过的流量。
  • 中转机上那个端口已经被你自己的 realm、gost 占着:填端口时面板会现问那台并提示。如果那正是你给这条线路做的转发,把「谁来转」改成「这台上已有转发」,面板就不去占它,只把入口写进订阅。
  • 删掉一台服务器时,经它中转的、转给它的中转入口一起去掉。
