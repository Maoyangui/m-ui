功能

按侧栏的顺序,面板管的每一件事。全部在一个二进制、一个 SQLite 文件里。手机上打开面板,列表自动排成卡片。面板右上角的帮助说明打开内嵌的使用说明(中英两份,带目录和页内搜索),直接定位到你当前所在页面的那一章;代理面板里打开的是代理视角的版本。

概览:最上面是需要处理,数据面重载失败、服务器离线或没同步、证书、大陆连通、上游故障、用户快到期或流量将尽、备份失败等每类一行,按轻重排,点行尾去处理,一切正常时只剩一行「✓」;下面一排数字是在线用户、24 小时流量、服务器和证书状态,点了直接跳到对应页面;再往下是流量走势、上游巡检、当前在线、最近入站连接、流量排行、最近操作、数据面状态和可收起的核心日志(手机上默认收起)。多服务器时流量走势和流量排行按全部服务器合计,卡片标题上注明范围。

线路上游用户套餐规则代理订阅服务器证书运维安全API

线路

线路 = 入口协议 + 端口 → 出口。协议:Hysteria2(支持端口跳跃和伪装站点)、AnyTLS、TUIC、Trojan、VLESS(Reality / Vision,握手目标可一键检测、帮你挑)、VMess、Shadowsocks(含 2022 系列),以及 SOCKS、HTTP、Mixed。传输层:WebSocket、gRPC、HTTPUpgrade、HTTP。每条线路可以部署到全部服务器或指定几台。勾上按规则分流,可以让指定的域名后缀、完整域名、域名关键字、IP 段或端口走另一个上游、直连或直接拦掉,其余流量走线路选的上游。快速添加自动填好空闲端口和合理参数;每次保存都经 sing-box 干跑,并检查端口是否与面板、其它线路、本机其它程序冲突。

上游

不直连时从哪出去:VLESS、VMess、Trojan、TUIC、Hysteria2、Shadowsocks、SOCKS 出站,粘贴分享链接即可导入。一键测延迟、定时巡检、故障 / 恢复告警,Cloudflare WARP 在面板里一键接入。巡检在真正用这条上游的机器上做:每台只测自己线路用到的那些,上游页一行里并排显示各服务器的延迟,告警会点名是哪台不通。改上游是热换出站,数据面不重启。线路也能直接加为上游(链式代理):参数跟着线路走,线路改端口、换协议都不用管,专用凭据不占用户配额,流量只算一次。上游组:几条上游放一组,自动用最快能通的,挂了自动换,面板写明现在走哪条。

用户

  • 配额(可到 0.1 GB)、到期(可设首次连接后 N 天,第一次有流量才开始计时)、周期重置、同时在线设备数(按源 IP:IPv4 地址与 IPv6 /64 各自计数,跨服务器取并集)、上下行限速。
  • 超量、到期自动禁用并踢线;订阅落地页会告诉用户原因。踢线、停用、换凭据对 Hysteria2、TUIC 这类 QUIC 连接同样当场生效,老连接立刻断开,不会再收发一阵。
  • 设备满了只拒新设备,已连着的不受影响;被拒的连接出现在概览的「最近入站连接」里并标红,也可以用「被拒」筛选单看。
  • 批量生成、批量启用 / 禁用 / 延期 / 重置 / 删除、CSV 导出、旧面板数据库导入。
  • 订阅地址可以是用户名也可以是随机令牌(设置里选);用户可自助生成临时共享地址,你随时能取消 —— 取消即刻断掉借用者。
  • 加人、停用、换凭据只是换入站的用户表,其他人不断线。

套餐

配额、时长、设备、限速、线路分配的模板,可以另填一个只给自己看的参考价。建号、续费、延期时一键套用。用户记着自己的套餐,套餐页能看到有多少人、是谁。

用户的「更多」菜单里:续费… 一次续 1–120 期(月付套餐按季、按年卖就填 3、12),可以续费(清零流量并顺延)、延期(保留已用流量)或只归入套餐;换套餐… 三种方式 —— 立即替换、叠加(保留旧订阅剩下的时间)、按两个套餐的参考价折算剩余价值。对话框实时预览变更前后,到期提前、马上超量这类让用户吃亏的影响标红,要勾确认才执行;单个用户的对话框带防重复编号,双击、网络重试都只执行一次。用套餐续费、延期、换套餐是明确的开通动作,手动停用的用户也会被启用,面板执行前会先提示。详情里的套餐记录能看到最近的续费和换套餐。

编辑套餐时可以勾选限速规则,这个套餐现有和以后的用户都跟着走。代理有自己的套餐,和你的分开。

规则

临时限速,叠在用户自己的限速之上。时段限速:每周指定几天的某个时间段(面板时区,可跨午夜)。突发限速:最近 N 分钟内跑了 X GB 就限 M 分钟,到期自动解除,再次达到再次限速;同一用户可挂多条,各自独立。目标可以是全部用户、某个套餐的用户(含以后套用的)、某个代理名下全部用户、或逐个勾选。规则由主机判定并同步到各副机,多条命中取最严;默认开着「不超过用户自己的限速」,结果不会高于用户自己的限速。改限速对在线连接立刻生效,不用等重连。用户列表标出「限速中」;落地页不显示。

代理

给代理分配一组线路,以及流量额度、设备池、带宽池和到期日。单个用户的设备数与限速由代理自己定;池限制的是名下所有用户同时的总量:设备池跨服务器算并集、池满只拒新设备,带宽池每台服务器各一份。代理有自己的面板(默认端口 2054,路径 /dl),在里面建用户、建套餐、设置自己的落地页标题、公告与联系方式,还可以开两步验证。所有用量汇总到代理;代理超额、到期或被停用时,名下用户一并断掉。代理的用户不会混进你的用户列表。

订阅

  • 一个地址三种格式:通用链接、Clash / Mihomo YAML、完整 sing-box JSON。发给用户的是不带参数的通用地址,客户端来拉时按类型给:Clash 系(Clash Verge、mihomo、Stash)拿 Clash 配置,sing-box 系(SFA、SFI)拿 sing-box 配置,其它拿通用链接;老内核 Clash 只拿到它认识的协议,SS-2022 这类会被滤掉。想指定就加 ?format=clash、?format=json,?format=mihomo 强制按新内核给;设置里也能关掉按客户端给格式。
  • 线路测速组:部署在多台服务器上的线路,Clash 和 sing-box 订阅里都各出一个按延迟自动选的组,组名就是线路名,节点名和顺序不变。线路名始终留给本站:外部订阅里和线路同名的节点改叫「X 2」,线路这次没出组时也一样,选过线路组的客户端不会被落到第三方节点上。
  • 每条线路按部署的服务器各出一个节点;分配可以细到某台服务器上的入口(用户、套餐、代理授权都支持);外部节点和外部订阅可以并进来;外部订阅可展开看每个节点的完整参数、在每台服务器上测速、从大陆三网测是否被墙、勾选后直接添加为上游,也可以隐藏、改名、按关键词排除(官网、到期这类信息节点),订阅刷新后仍然生效。
  • Clash 与 sing-box 各可写一份模板,节点和分组由面板填;写错保存时就报错。
  • 浏览器落地页:用量、到期、公告、佛跳墙 / Clash / 小火箭 / Nextin / sing-box / Hiddify 一键导入、Clash / 通用 / sing-box 三个二维码、客户端下载页、临时共享。
  • 落地页可以换成自己的 logo:主面板和每个代理各一张,支持 PNG、JPEG、GIF、WebP、SVG,上传时在浏览器里缩小并转成 PNG,上传即生效;访客用深色模式时 logo 下面垫一块浅色底,设置里并排预览两种效果。logo 随快照同步到副机、随备份走。
  • 公告和页脚联系方式能写链接,页面上只显示文字:客服(https://t.me/example)、[教程](https://example.com/a)、裸地址、Tg: @username、WhatsApp: +号码。只认 http(s)、tg、mailto、tel 链接;公告最多 4000 字、联系方式最多 300 字。
  • 可选的顶部流量提示节点;自签证书自动给客户端加 insecure。
  • 失效的订阅给一页说明和你的联系方式,而不是空白的 404。

服务器

一主多副。主机每 5 秒推送线路、上游、用户、凭据,拉回流量增量与在线 IP;副机只管转发。每台服务器可设流量倍率,线路按服务器部署,双栈服务器可按线路选 IPv4 或 IPv6,连接跟踪跨服务器汇总;大陆连通检测从移动、电信、联通的家宽测点定时测每台服务器,被墙就发 Telegram。

IPv6 入站检测:服务器默认走 IPv6、或有线路选了 IPv6 时,同一轮从境外的 IPv6 测点连它的 IPv6 地址和线路端口,结果标在服务器页和线路上;UDP 线路(Hysteria2、TUIC)测不了,会写明。概览的最近入站连接按服务器列出谁连进来了、走的哪条线路;被设备数或代理设备池拒的标红;到了但没过 TLS / REALITY 握手或协议认证的来源在「握手失败」筛选里并写明原因,排查"用户说连不上"时先看这里(有几类失败不会被记录,比如 Hysteria2 / TUIC 的 QUIC 握手失败,卡片标题旁的「?」里列着)。

设为主机与主机容灾:设为主机一键把主机换到另一台服务器,数据端到端加密交接过去,原主机自动变为副机,换到全新 VPS 也不用备份还原(交接时写操作暂停一两分钟,这两台自己线路上那一两分钟的流量不计入用量)。主机容灾(默认关闭)让排在前面的几台副机当备用,保存加密的数据副本;主机失联时按你选的方式接任:先确认再接任(默认,Telegram 回复确认码或在备用面板上点接任)或主机失联后自动接任。纪元只升不降防脑裂,原主机回来自动变为副机;主机变了可以用 Cloudflare 令牌自动改订阅域名的解析(默认关闭)。和副机的链接是明文 http 的,设为主机要勾风险确认,默认也不当备用。命令行 m-ui ha status | takeover | set-master | pause | resume。

详见 多服务器。

证书

一台服务器可以放多张证书。Let's Encrypt,HTTP-01、Cloudflare DNS-01 或手动 DNS,支持泛域名,签发前预检 DNS 与端口。没有域名一键自签。也可以用自己的证书文件。线路默认、面板、订阅各选各的,每条线路也能单独选一张,抽屉里按服务器标出哪台有、还剩几天。

自动续期:启动几分钟后先查一次、之后每小时查,进入有效期最后三分之一就续(90 天的证书剩 30 天时),续好后热更新不重启。失败按 1、2、4 小时退避重试,第一次失败就通知;证书库里每张都写着能不能自动续、上次续期、失败次数和下次重试时间,也能单张关掉自动续期或立刻续。副机一般不配通知,它的续期失败、快到期由主机代发提醒。手动 DNS 签的证书不能自动续。面板、订阅、代理面板的证书文件万一读不出来,先用临时自签证书顶着启动并在顶部提醒,不会整个起不来。

运维

  • 备份 / 还原:数据库与证书打成一个 zip(设置里引用的数据目录外的证书文件也在内),每日定时备份(按面板时区),面板里还原,换机向导迁到新机器。还原时数据目录外的证书:这台原路径上有能用的同一张就接着用;没有才把备份里的副本放进 /etc/m-ui/cert/restored/ 并改好设置。这些副本没有工具再续,面板顶部提示一次、证书页单独标出,要重新签发或重新添加。
  • 内核调优、WARP 安装、限制系统日志占用都在运维页完成,日志实时输出到浏览器。
  • Telegram 与 Webhook:数据面、上游、副机故障告警,用户即将到期 / 用完提醒,按面板时区发日报。Telegram 机器人可以在手机上查用户、续期、重置流量、启停、要备份,只听你设置的会话。
  • 更新:面板每 6 小时查一次 GitHub Releases;一键校验摘要、替换程序、重启。数据、证书、设置不动。副机也用同样的方式自己更新。
  • 面板内看日志与审计记录,订阅访问日志与审计各自可设自动清理天数;SSH 菜单(m-ui)负责端口、路径、密码与应急恢复。

安全

两步验证(TOTP)、按 IP 的登录限速、按角色隔离的会话、服务端强制的代理隔离、安装脚本与更新器都校验摘要、没有遥测。任何配置改动都绕不过校验。

外部 API

令牌鉴权的 HTTP API:建用户、改用户、启停、读用量、取订阅链接 —— 给发卡站、机器人和自动化用。套餐操作:/plan(别名 /renew)一次续 N 期,/change 换套餐(立即替换 / 叠加 / 按参考价折算),/plan-ops 查套餐记录。带 dryRun 只预览不执行(商城可以拿来报价);带 requestId 或请求头 Idempotency-Key(比如订单号),重试只执行一次;会让用户吃亏的换套餐返回 409,确认后带 force 再调。续费、换套餐会启用手动停用的用户。代理有自己的令牌,只能动名下的用户和自己的套餐。管理员页的接口一览带着填好前缀和令牌的 curl 示例。见 docs/API.md。
