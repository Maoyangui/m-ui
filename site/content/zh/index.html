Maoyangui 的 sing-box 面板

一个二进制就能跑的 sing-box 面板

m-ui 把 sing-box 内嵌进面板,而不是在旁边看着一个外部进程。改用户、换上游都是热更新,别人不断线;每次保存先交给 sing-box 干跑;一台主机把任意多台副机同步好。

五分钟装好 在线演示 GitHub 
bash <(curl -fsSL https://raw.githubusercontent.com/Maoyangui/m-ui/main/deploy/install.sh)

一个静态二进制不用 Docker、不用外部数据库改用户、换上游不断线一主多副GPL-3.0

为什么是 m-ui

不是又一个套壳面板。下面这些才是真正不一样的地方。

内嵌 sing-box

内核跑在面板进程里。不用单独装、不用对版本、不用手动重启,面板在进程内直接操作它。

一条线路就是一件事

入口协议 + 端口 → 从哪出去。不用分别维护入站、出站、路由三张表。Hysteria2、AnyTLS、TUIC、VLESS Reality、Trojan、VMess、Shadowsocks 2022。

改用户、换上游不断线

加人、停用、换凭据只是换入站的用户表;换出口只是换出站。其他人的连接一个都不掉。

先校验再上线

每次保存先让 sing-box 解析一遍,坏配置进不了库;新配置万一起不来,自动回滚到上一份能用的。

一主多副

线路、用户、凭据每 5 秒推给所有副机;流量和在线 IP 回收到主机,配额与设备数统一判定。

运维不用回终端

Let's Encrypt、Cloudflare WARP、内核调优、备份还原、换机向导、Telegram 通知、两步验证、一键更新,都在面板里。

从空服务器到第一条订阅

域名是推荐项,不是前置条件 —— IP + 自签证书是完整支持的路径。

  1. 安装Debian / Ubuntu 一条命令,打开 :2053/app/ 登录。
  2. 证书有域名就签发,没有就一键自签。
  3. 线路快速添加里选个协议,空闲端口自动填好。
  4. 用户建第一个用户,详情抽屉直接打开:订阅地址和二维码就在眼前。
  5. 订阅Clash、sing-box、通用链接三种格式,外加一页带用量和一键导入的落地页。

先答几个问题

一定要有域名吗?

不用。一键自签证书,直接用服务器 IP;订阅里会自动告诉客户端允许不安全证书。有域名可以签正式证书,客户端就不再提示。

是某个面板的分支吗?

m-ui 有自己的数据模型(线路,而不是入站 / 出站 / 路由三张表)、自己内嵌的数据面和自己的同步协议。它能导入旧面板的数据库,割接后既有客户端不用刷新订阅就能继续连。

会不会偷偷上报?

没有遥测。对外的请求只有你自己配置的:签证书、WARP、Telegram,以及每 6 小时向 GitHub Releases 查一次新版本。

跑在什么上面?

Linux,amd64 或 arm64,systemd。面板本身 1 核 1 GB 的小鸡绰绰有余。
