m-ui vs s-ui

Both are sing-box panels, both GPL-3.0, both single-author projects with a web UI. If you already know s-ui, this page answers one question: when is m-ui the better fit, and when is it not? Facts checked on 2026-09-05 against s-ui's README and release page (v1.6.0, 2026-09-01); anything s-ui does not state is marked Unknown.

The one-paragraph version

s-ui is the established sing-box panel: nearly 10k stars, years of releases, a large protocol list and a familiar inbound / outbound / routing model with a form for each. m-ui is newer and narrower on purpose: it embeds sing-box in the panel binary, replaces the three config tables with lines, hot-swaps users and upstreams without restarting, validates every save with sing-box's own parser, and is built around one master syncing any number of nodes. If you run one server and like editing configuration in detail, s-ui is a safe choice. If you run several servers or change users all day, m-ui was built for that.

Choose s-ui if

  • You want the panel with the larger community, more tutorials and a longer track record.
  • You like configuring inbounds, outbounds and routing explicitly, or need a protocol m-ui does not expose (ShadowTLS, Naive, TProxy, Redirect).
  • You run one server and do not need central quota across machines.

Choose m-ui if

  • You run two or more servers and want users, quotas and device limits to be one thing.
  • You add and remove users often and do not want a restart each time.
  • You want configuration mistakes caught before they reach the running core, with automatic rollback.
  • You resell and need isolated reseller panels with budgets.
  • You want a single binary you can back up, move and update without Docker.

Moving between them

m-ui can import a compatible legacy panel database and keep ports, credentials and subscription paths so existing clients continue without a refresh. Try it on a copy of your database first and read the importer's report; it lists what was mapped and what was skipped. See Getting started.
