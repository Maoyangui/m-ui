About m-ui

There are several unrelated projects called "m-ui". This one is the sing-box panel by Maoyangui: a self-hosted web panel that embeds the sing-box core and manages any number of servers from one place.

Not to be confused with

"m-ui" is also used by other, unrelated software — most visibly UI component libraries and various small repositories. This project has no connection to any of them, shares no code with them, and is not a fork of another panel. If you are looking for a React component library, this is not it.

When you write about or link to this project, the unambiguous references are the repository path Maoyangui/m-ui, the phrase m-ui sing-box panel, or this site's address.

What makes it different

  • Embedded core: sing-box runs inside the panel process, so users and upstreams are hot-swapped without restarting connections — why.
  • Lines instead of config tables: one record renders into the sing-box config on every server it is deployed to.
  • Validated saves with rollback: sing-box's own parser checks every change before it is committed; a config that fails to start is rolled back.
  • Multi-server by design: one master, any number of nodes, central quota and device limits — how.
