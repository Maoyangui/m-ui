m-ui 帮助说明代理面板帮助说明

按目录找功能(手机上点右上角的「目录」),或者用上面的搜索框。灰框里的字和面板上的按钮、标题一模一样,照着找、照着点就行。这里只列代理面板用得上的内容。

快速上手

m-ui 是一个自己搭的代理面板:线路、用户、订阅、证书、备份和多台服务器,都在网页里管。

代理面板用来管你名下的用户:建号、续费、看用量,再把订阅地址发给用户。

先认识几个词

面板里反复出现这几个概念,弄清楚了后面就好懂。

  • 线路:客户端连进来的入口,等于"协议 + 端口",再决定流量从哪出去。用户订阅里的节点就是由线路生成的。
  • 上游:线路的出口。默认 direct(本机直出),也可以是 WARP 或别的落地机。
  • 用户:一个订阅地址,带流量、到期、设备数和限速。流量用完或到期会自动停用;设备数满了只拒绝新设备,限速只限制速度。
  • 套餐:流量、时长、设备数、限速、线路的模板,建号、续费时一键套用。
  • 订阅:给客户端导入的地址;同一个地址用浏览器打开,是用户自己的落地页。
  • 主服务器 / 副服务器:主机存全部数据、负责算账;副机只转发流量,配置由主机推送。
  • 代理:帮站长卖号的人,在自己的代理面板里只管自己名下的用户。

第一次登录

装好后用浏览器打开面板,第一件事是把默认密码改掉。

  1. 打开 http://服务器IP:2053/app/(端口和路径以安装结束时打印的为准)。
  2. 用默认账号 admin / admin 登录。
  3. 顶部红条提示还是默认密码:点 立即修改,在 管理员 页的 登录账号 里填 原密码 和 新密码,点 更新账号,然后用新密码重新登录。
常见坑
  • 只打开 http://服务器IP:2053/ 会是 404,这是故意的:不把面板路径告诉扫端口的人。地址要带上完整路径。
  • 打不开:先看云服务器的安全组 / 防火墙有没有放行 2053/tcp。
  • 忘了地址或密码:SSH 登录服务器执行 m-ui,菜单 1 查看面板地址,菜单 5 重置管理员密码。

五步开始用

概览页的 快速开始 清单就是这几步,做完前四步就能给人用了。

  1. 改默认密码(见上一节)。
  2. 准备证书:证书 页 → 添加证书。有域名选 有域名(自动签发) 签一张;没有域名选 无域名(自签),点 生成自签证书。详见 证书。
  3. 建线路:线路 页 → 快速添加,新手选 Hysteria2 或 AnyTLS,保存。详见 线路与协议。
  4. 建用户:用户 页 → 新增用户,填用户名和额度,勾上 可用线路,保存。
  5. 发订阅:点用户名打开详情,订阅 下面有两个地址,把不带 ?format= 的那个(通用地址)发给用户:用浏览器打开是他自己的落地页,能一键导入客户端;客户端来拉时按类型给格式(见 订阅地址、二维码与临时共享)。
没有域名也能用自签证书 + 服务器 IP 就行:订阅会自动告诉客户端"允许不安全证书",客户端不用另外设置。以后有了域名签正式证书时注意:证书页默认勾着 用于订阅 HTTPS,勾了订阅地址就变成 https://域名…,要把新地址发给每个用户;不想换地址就取消这个勾,用户刷新一次订阅即可。
常见坑线路的端口要在云服务器安全组和系统防火墙里放行:Hysteria2、TUIC 走 UDP,其它大多走 TCP。没放行是"连不上"最常见的原因。

代理:三步开始用

站长给你开通代理之后,按这三步就能开始卖号。

  1. 打开站长给你的代理面板地址(默认端口 2054,路径 /dl/)。用户名填代理名,第一次登录密码留空,直接点 登录,按提示设置密码。详见 第一次登录与设密码。
  2. (可选)到 套餐 页建几个套餐,以后建号、续费一键套用。
  3. 到 用户 页点 新增用户:填名称,选套餐或者手填额度,勾上 可用线路,保存;点用户名打开详情,把 订阅 下不带 ?format= 的那个地址发给用户。
代理面板只有四页概览、用户、套餐、账号。你只看得到自己名下的用户和自己建的套餐。

界面导览

左边是功能导航,右上角是帮助和反馈,页面顶部的彩色横条是需要你处理的提醒。

  • 左侧导航依次是:概览、线路、上游、外部节点、用户、代理、套餐、规则、服务器、证书、备份、运维、日志、管理员、设置。
  • 左下角:主题切换(◐ 跟随系统、☀ 浅色、☾ 深色)、语言、退出登录。版本号旁出现箭头表示有新版本,点它就能更新(见 更新)。
  • 右上角:帮助说明(就是本页)和 建议 / 支持(联系作者、反馈问题)。
  • 顶部提醒条:默认密码没改、证书要处理、大陆连通异常、数据面重载失败等,按提示处理;能关的点 知道了。
  • 副服务器的面板里,线路、用户这些页面是只读的,要到主机面板改。

服务器与主副机

一台主服务器管全部数据,可以再接任意多台副服务器当入口;订阅里每条线路在每台服务器上各出一个节点,客户端挑延迟低的用。

要不要加副机

一台服务器就能用;想给用户更多地区、更多入口时再加副机。

  • 主机每 5 秒把线路、用户推给副机,同时收回各台的流量和在线设备;配额、到期只在主机上判定。
  • 副机只转发流量。主机临时连不上时,副机继续按最后一份配置服务用户;恢复后流量按记录补齐,不会重复计费。
  • 加一台服务器,所有人的订阅里自动多出对应的节点。

接入一台副机

在副机上装好 m-ui,把它的配对信息填到主机就行。

  1. 在副机服务器上同样安装 m-ui,登录副机面板(先把默认密码改掉)。
  2. 副机 设置 → 角色:勾 作为副服务器运行,点 保存。
  3. 副机 设置 → 配对信息:复制 API 地址 和 配对令牌。
  4. 主机 服务器 页 → 新增服务器:填 名称(会成为订阅里节点名的后缀,如"香港")、API 地址和配对令牌。副机面板用自签证书或 IP 访问时勾 跳过证书校验。
  5. 保存后几秒,这一行显示 已同步 就好了。
常见坑
  • API 地址是 http:// 时,令牌和全部用户凭据都是明文传输,列表里会标 明文。建议给副机面板开 HTTPS(自签就行),或者让副机面板端口只对主机 IP 放行。
  • 副机的证书在副机自己的 证书 页签发,各自续期。
  • 副机面板改成 HTTPS 后(副机证书页勾了 用于面板 HTTPS,重启后生效),要到主机 服务器 页编辑这一行,把 API 地址 换成副机 配对信息 里新的 https:// 地址(自签证书或用 IP 访问的勾 跳过证书校验),不然这台会显示离线。在副机上签正式证书时这一项默认勾着,不打算改 API 地址就取消它。
  • 副机面板里线路、用户、套餐这些页面是只读的,改动都在主机上做。
  • 主副机版本要一致:列表里标 版本与主机不同 时,把副机升级到同一版本。用到较新的功能后,版本不够的副机会整份拒收同步、继续按旧配置服务:按规则分流要 v0.6.14 及以上,线路作上游、上游组、外部节点的排除关键词要 v0.7.16 及以上,外部节点的隐藏和改名要 v0.7.17 及以上。

连接地址与 IPv4 / IPv6

订阅里的节点地址默认用每台服务器自动探测到的公网 IP,域名只作 SNI,免得客户端 DNS 被污染连不上。

  • 编辑服务器 → 连接地址(可填 IP):留空就用探测到的公网 IP;想用固定的 IP 或域名就手填。
  • 自动地址用:双栈服务器默认给 IPv4,可以改成 IPv6;选的那个没探测到就用另一个。手填了连接地址就不看这一项。
  • 双栈服务器在线路表单里还能按线路单独选 IP 版本。
  • 想让订阅里写域名而不是 IP:设置 → 订阅 → 订阅里的节点地址 选 域名。选之前先给每台服务器填好 域名 / IP(本机留空就用面板域名):这个模式下 连接地址(可填 IP) 不生效,没填域名的服务器不会出现在订阅里。
IPv6 入站检测服务器默认用 IPv6、或者有线路选了 IPv6 时,主机会从外面测它的 IPv6 端口能不能连进来,结果标在 服务器 页。显示不通,多半是安全组没放行 ::/0 或者本机防火墙拦了 IPv6。UDP 线路(hysteria2、tuic)测不了,只能在服务器上抓包确认。
IPv6 常见坑
  • 云服务器的 IPv6 要在安全组里给 ::/0 单独放行(TCP、UDP 分开加);系统里的 ip6tables / ufw 也要放行,只清空 iptables 不会放开 IPv6。
  • WARP、NAT 这类只能出站的 IPv6 不能给用户连。
  • 纯 IPv6 的机器:检查更新前要先装 WARP(见 WARP);直连出口打不开只有 IPv4 的网站,线路上游选 warp 才能访问全网。

流量倍率

给贵的服务器多扣流量:经过这台服务器的流量按倍率计入用户用量。

  • 编辑服务器 → 流量倍率:2 就是双倍扣量,节点名会带 x2 标记;1 是原样。主机自己也能设。
  • 用户的已用量、详情里的流量图、落地页上的数字都是折算后的,账对得上;线路、上游的统计是实际流量。

大陆连通检测

看服务器在中国大陆是不是被墙了:从大陆移动、电信、联通的家庭宽带测点去连,香港测点作对照。

  • 服务器 页的 大陆连通 一列显示结果:点格子看明细,点 检测大陆连通 一次测全部。
  • 结果怎么看:正常;部分不通(某一家运营商连不上);疑似被墙;IP 被墙(要换 IP);端口被封(换个端口);境外也不通(是服务器、端口或安全组的问题,不是墙)。
  • 定时巡检:设置 → 大陆连通检测 → 自动巡检,默认开着:m-ui 启动约 2 分钟后测第一轮,之后默认每 90 分钟一轮,发现被墙或恢复时发 Telegram。
常见坑
  • 检测时服务器地址(IP 和端口)会发给 Globalping 公共测试网络,自动巡检也一样;不想发就去掉 自动巡检,只在需要时手动点检测。免登录每小时约 250 个测点次,测一台约用 15 个;不够用就在设置里填免费申请的 Globalping 令牌(可选)。
  • 测的是这台第一条 TCP 线路的端口;只有 hysteria2、tuic(UDP)线路时,只能看出 IP 有没有被墙。目前只测 IPv4。

停用、删除与离线排查

停用或删除副机会让它立刻停止服务;副机显示离线时,先看列表里写的原因。

  • 编辑服务器去掉 启用:那台立刻停止为任何人服务,重新启用后恢复。
  • 删除服务器:只部署在它上面的线路会被停用,只用它的用户 / 代理会失去那条线路;操作后会列出受影响的线路和人。
  • 标 下线通知未送达:那台还没收到停止服务的通知,主机会一直重试。要立刻停掉,就 SSH 到那台机器上执行 systemctl disable --now m-ui(停掉并取消开机自启),或者用 m-ui 菜单 14 卸载。只关掉副机模式停不了服务:它会变成一台独立的主机,按最后一份配置继续给所有人用。
  • 离线原因:连接超时、连接被拒绝(端口没放行或面板没在运行)、域名解析失败、证书不受信任(勾上跳过证书校验)、令牌不匹配(重新复制配对令牌)、证书指纹变了(确实重签过副机证书,就点 重置指纹)。
  • 换一台副机:新副机装好后,在 服务器 页编辑原来那一行,换成新的 API 地址和令牌,主机会自动重新推送。

设为主机与主机容灾

两件事:设为主机 一键把主机换到另一台服务器(计划内换机、换到全新 VPS 都用它);主机容灾 在主机挂了(VPS 宕机、被误删)时由备用接任为主机。容灾默认关闭。

设为主机

在主机面板上把任意一台副机设为主机:数据一次交接过去,原来的主机自动变为副机。

  1. 服务器 页,点那台服务器 状态 一栏开头的角色标签(如「副机 ▾」「备用 1 ▾」),在弹出的卡片里点 设为主机;行末的 ⋯(更多)菜单里也有。
  2. 确认框里写清会发生什么:检查结果、新的面板地址、订阅域名的 DNS 该指向哪个 IP。输一次管理员密码(开了两步验证再输动态码)。
  3. 之后全程有进度,完成后给出新面板地址。账号、密码、两步验证都不变,到新面板重新登录。
  • 主机的全部数据(用户、线路、套餐、代理、设置、流量记录)端到端加密后交给那台,它成为主机;原来的主机变为副机,继续用自己的线路服务。两台各重启一次,连在这两台上的用户断开几秒后自动重连,别的服务器不受影响。
  • 中途任何一步失败都会自动取消:原主机照旧当主机,写操作恢复,数据不变。
  • 换到全新 VPS:照常装好 m-ui,像副机一样接入(见 接入一台副机),显示 已同步 后对它点 设为主机,不用备份、还原。
  • 订阅地址不变:订阅的域名、端口、路径和证书跟着主机走,把订阅域名的 DNS 改指向新主机就行(订阅地址用的是 IP 时会变,确认框会提前说)。面板和代理面板用新主机自己的地址。
  • 离线、配置没同步上、版本太旧、磁盘不够、端口冲突的副机不能设为主机,卡片里写明原因。
常见坑交接期间写操作暂停(一般几分钟,最多 15 分钟):面板只读,外部 API、代理面板、Telegram 机器人的写操作返回 503,对接的程序要能重试。

主机容灾怎么工作

在主机的 设置 → 主机容灾 里打开(保存时要输管理员密码)。开启后,服务器顺序排在最前面的几台副机当备用,保存加密的数据副本。

  • 备用台数 默认 2(可设 1–3),按 服务器 页的顺序挑,列表里标「备用 1」「备用 2」;调顺序就是调谁先接任。
  • 主机定时把数据副本发给备用(默认每 5 分钟一份,有改动后 30 秒内补一份)。副本用备用自己的公钥加密、主机签名,只有接任时才解开。
  • 主机失联期间副机照常转发,已连上的用户不受影响;接任是为了恢复管理、计费、订阅和告警。
  • 接任后它就是主机,可以长期当。副机线路上的流量会自动补回;最后一份副本之后在原主机上做的管理改动、原主机自己线路上那几分钟的流量补不回来。
  • 设置页的 就绪检查 逐项打勾:合格的备用、副机版本、副本自检、和备用的链接是不是 https、订阅是不是用域名、Telegram、副机之间是否互通、境外见证;没通过的给一句修法。
常见坑
  • 副机都要升级到 v0.7.17 或更新:旧版照常同步,但不能当备用。
  • 副机之间要互相放开面板端口,好互相确认主机是不是真的失联;不通时只能靠境外测点或人工确认。
  • 备用重装过 m-ui,它的公钥会变:卡片里点 重新信任 后才会再给它发副本。

接任方式

打开容灾时三选一,默认是确认后再接任。

  • 关闭:主机挂了要人来处理,副机照常用自己的线路服务。
  • 主机失联后确认再接任(默认,推荐):备用发现主机失联 3 分钟后发 Telegram,回复消息里给的 /takeover 码(或「接任 码」),或者到备用的面板上点 接任为主机,它就接任。主机在这之前回来,提醒自动取消。
  • 主机失联后自动接任:失联 10 分钟后备用自己接任。三台以上要过半副机同意;一主一副时还要境外测点也连不上主机,所以必须开着 境外测点见证。
  • 什么算失联:备用 1 分钟以上没收到主机的消息,其它副机也联系不上它,境外测点(美、德、日、新、港)也连不上它的公网 IP。只是国内到主机被墙、某一台和主机之间断网,或者主机在升级、重启,都不算。
  • 防脑裂:每次接任或设为主机都换一个更高的纪元,副机只听纪元最高的那台。
  • 等多久发确认、等多久自动接任、副本间隔,都在 高级 里调。
常见坑
  • 升级、维护前可以先暂停接任(设置页的暂停按钮,或主机上 m-ui ha pause 分钟数);在面板里点升级、改端口这类会重启的操作,会自动暂停一会儿。
  • 没开 Telegram 通知时,确认模式只能到备用的面板上点接任。
  • 订阅地址里是 IP 时,接任后用户要重新导入订阅。订阅最好用域名,接任后把它指向新主机(或者打开下面的 Cloudflare 自动改 DNS)。

原主机回来了

原主机恢复后自动变为副机,不会和新主机抢着当主机。

  • 新主机的服务器列表里它先标「原主机 · 失联」,暂时不进订阅;回来后变回「副机」,重新收到配置,线路回到订阅。
  • 它失联期间如果还收了改动,变为副机前会先留一份备份,页面顶部提示有几条改动没进新主机。
  • 想让它重新当主机,在服务器列表里对它点 设为主机。

Cloudflare 自动改 DNS(可选)

订阅域名托管在 Cloudflare 时,主机变了(接任或设为主机)可以自动把解析改到新主机。默认关闭,要一个 Cloudflare API 令牌。

  • 在 主机容灾 设置的 高级 → 自动改 DNS(Cloudflare,可选) 里填 Cloudflare 令牌 和 跟着主机走的域名(比如订阅域名),点 测试令牌与记录 看哪些记录会被改。
  • 令牌要有这个域名的 DNS 编辑权限,单独存、和签证书用的分开;怎么创建见 Cloudflare API 令牌怎么创建。
  • 只改这些域名里当前指向原主机 IP 的 A / AAAA 记录,橙云和 TTL 不动,别的记录不碰;改不成只告警,不挡换主机。
  • 不配的话,接任或设为主机后按页面顶部和 Telegram 里写的 IP,自己去改解析。

命令行

SSH 到服务器上用 m-ui ha(要 root);m-ui 菜单第 15 项也是主机容灾。

  • m-ui ha status:本机角色、纪元、模式、备用、副本时间;服务停着时也能看个大概。
  • m-ui ha takeover:在备用上接任为主机,主机还在联系它时会被拒绝;加 --force 不管主机有没有联系都接任,只在确认主机已经不在、或两台主机僵持时用。
  • m-ui ha set-master 服务器名或 id:在主机上把一台副机设为主机,做完打印新面板地址。
  • m-ui ha pause 分钟数 / m-ui ha resume:在主机上暂停 / 恢复接任。

线路与协议

线路决定客户端怎么连进来:入口协议 + 端口 → 从哪出去。每条线路在它部署的每台服务器上各出一个节点。

新建线路

新手用 快速添加 最省事:协议参数是配好的,端口也自动挑好。

  1. 线路 页右上角点 快速添加,选一个预设:Hysteria2、AnyTLS、VLESS + Reality、Trojan、Shadowsocks 2022、VMess + WS。
  2. 表单已经填好,看一眼 名称(订阅里显示的节点名)和 端口,保存。
  3. 想自己配就点 新增线路:选 协议、填端口;上游 默认是 direct(本机直出)。
  • 新建时默认勾着 分配给全部现有用户(不含代理名下);不勾的话,要到用户里逐个勾上,新线路才会出现在他们的订阅里。
  • 端口会自动填一个空闲的五位数端口,可以改;和面板、订阅端口或本机其它程序撞了,保存时会直接报错。
  • 保存前整份配置先交给内核试跑,过不了就不生效,也不影响正在用的线路。改线路会让数据面重启一下,在线用户会自动重连。
常见坑端口要在安全组 / 防火墙放行,UDP 协议(Hysteria2、TUIC)记得放 UDP。

协议怎么选

拿不准就这样配:主力用 Hysteria2,再配一条 TCP 的(AnyTLS 或 VLESS + Reality)当备用。

协议走证书特点 / 适合
Hysteria2UDP需要(自签也行)速度快、抗丢包,首选。运营商限 UDP 时配端口跳跃。
TUICUDP需要和 Hysteria2 同类(基于 QUIC),作备选。
AnyTLSTCP需要流量特征弱;UDP 不好用时首选的 TCP 方案。
VLESS + RealityTCP不需要不要域名和证书,借大站的 TLS 握手,抗探测强;建议开 Vision。
TrojanTCP需要经典的 TLS 协议,客户端基本都支持。
VMess / VLESS + WSTCP可选能套 CDN(要有域名);直连时不如上面几种。
ShadowsocksTCP / UDP不用不要证书,客户端支持最广。2022 算法更安全,但老内核 Clash 不支持,订阅会自动不发给它们。
SOCKS / HTTP / MixedTCP—普通代理,适合内网设备或给别的程序当中转,不建议直接拿来翻墙。
没有域名时VLESS + Reality 最省事;也可以用自签证书跑 Hysteria2 / AnyTLS,订阅会自动带上"允许不安全"。

TLS:节点证书、Reality、无

TLS 模式 决定节点怎么加密和伪装;Hysteria2、TUIC、AnyTLS 必须用 TLS。

  • 节点证书:用本机证书,客户端按域名校验。默认用每台服务器证书页设的默认证书,也可以在 证书 里给这条线路单独选一张。
  • Reality:不用证书,伪装成 握手目标(伪装域名) 那个网站的 TLS。点 检测 看能不能用,点 帮我挑 自动测一批常见大站、按延迟列出,点一下就填入。私钥 旁边点 生成密钥对,Short ID 旁边点 生成。
  • 无:明文,只用于 CDN 回源或内网。
  • 客户端指纹 一般保持默认。
常见坑
  • Reality 的握手目标要支持 TLS 1.3 和 H2,并且从服务器连得上;线路部署在别的服务器时,检测出的延迟只作参考。
  • 用自签证书时客户端要允许不安全证书:订阅里会自动带上,一般不用管(设置项是 订阅允许不安全证书)。

传输方式

只有 VLESS、VMess、Trojan 能选 传输方式;拿不准就用默认的 TCP(直连)。

  • TCP(直连):最快。
  • ws、httpupgrade:可以套 CDN。
  • grpc:适合配 Reality。
  • VLESS 建议勾 启用 XTLS Vision(仅 TCP + TLS,推荐)。

Hysteria2 的端口跳跃与伪装

运营商对单个 UDP 端口限速时用端口跳跃;不想被人探测出是代理,用伪装站点。

  • 端口跳跃范围:比如 20000-30000。服务器把这一段 UDP 端口都转到线路端口,客户端在范围内随机换端口。安全组 / 防火墙要放行这整段 UDP;留空就是不用。
  • 伪装站点:别人探测这个端口时看到的是这个网站,而不是一个报错的代理。要写完整网址,新线路默认 https://www.bing.com;留空 = 不伪装。
  • 上行带宽 Mbps(0=不限) / 下行带宽 Mbps(0=不限):一般留 0。
  • 混淆密码(salamander,留空=不用):一般留空;填了的话订阅会自动带给客户端。

部署到哪些服务器

有多台服务器时,一条线路可以只在其中几台上开。

  • 部署到服务器:默认全部勾着 = 全部服务器,以后新加的服务器也会自动开这条线路(全都不勾也按全部算);只勾其中几台,才是只在这几台上开,订阅也只出这些入口。
  • 双栈服务器那一行多一个下拉,可以让这条线路在那台单独用 IPv4 或 IPv6(默认跟服务器页的设置)。
  • 一条线路部署在几台服务器上就是几个"入口";给用户、套餐、代理分配线路时,可以只勾其中某台服务器上的入口。

按规则分流

同一条线路里,让指定的网站走别的出口(比如流媒体走解锁机),或者直接拦掉。

  1. 编辑线路,勾 按规则分流。
  2. 点 + 添加规则:选 匹配方式(域名后缀、完整域名、域名关键字、IP 段、端口),填匹配内容(多个用逗号或换行隔开),选 出口:direct、某个上游,或者 拦截。
  3. 想按应用加:在旁边的输入框填应用名(如 抖音、netflix、openai),点 查域名,规则自动加好,出口在规则里选。
  4. 保存。
  • 从上往下,第一条命中的生效;都没命中的走线路自己的 上游。
  • 一个 App 常常要好几个域名,要一起加;关键字太短(比如 ai)会误伤别的网站;按域名访问的流量不一定能按 IP 段匹配上,优先用域名规则。
  • 取消勾选 按规则分流 再保存,会清掉全部规则。

批量操作、排序与克隆

勾选多条线路后,顶部会出现批量操作条。

  • 启用、停用、设上游、部署服务器(有多台服务器时才有)、取消选择。批量改只重载一次数据面。
  • 拖动行调整顺序,订阅里的节点按这个顺序排。
  • 行末 ⧉ 是 克隆(会重新挑一个端口),⇢ 是 把线路加为上游(见 线路作上游)。

上游与外部节点

上游决定线路的流量从哪出去;外部节点把别处的节点并进用户的订阅。

添加上游

上游就是"落地机":加好后在线路的 上游 里选它,用户的流量就从那台机器出去。

  1. 上游 页 → 新增上游。
  2. 把落地节点的分享链接粘贴到 从分享链接导入,点 解析填表,核对后保存;也可以手动选类型、填参数。
  3. 点 测试 看延迟;再到 线路 里把线路的上游改成它。
  • 支持 VLESS、VMess、Trojan、TUIC、Hysteria2、Shadowsocks、SOCKS 落地。
  • 还有线路在用的上游删不掉,先把那些线路的上游改掉。

WARP

Cloudflare WARP 给线路一个干净的出口,常用来解锁流媒体,或者让纯 IPv6 的机器访问 IPv4 网站。

  1. 运维 页的 Cloudflare WARP 卡片里,依次点 安装、启用。
  2. 点 检测出口,确认出口 IP 正常。
  3. 上游 一栏还没有 warp 的话,点 添加为上游 warp。
  4. 在线路的上游里选 warp。
常见坑
  • WARP 的本地端口(SOCKS5 端口)默认 40000,被占用会启用失败;改了端口要重新启用。
  • 一键安装只支持 Ubuntu / Debian;其它系统要自己装 cloudflare-warp(代理模式),让它的 SOCKS5 监听同一个端口。运维任务只在 Linux 上、m-ui 以 root 运行时能用。
  • 有多台服务器时,warp 上游指向的是每台服务器自己的 127.0.0.1:端口:用 warp 的线路部署在哪几台,就要在哪几台的 运维 页都安装并启用 WARP(端口和主机一样);做不到就把这条线路只部署到装了 WARP 的服务器。

线路作上游(链式代理)

让入口线路的流量再转到你自己的另一条线路出去,比如国内中转机进、海外机出。

  • 上游 页点 把线路加为上游(或在线路行末点 ⇢),选线路和 用它在哪台服务器上的入口。
  • 参数跟着线路自动走,线路改端口、换协议都不用管;用的是专用凭据,不占用户配额,流量只算一次。
  • 成环、线路被删、入口服务器被删都会被拦下或标出来。副机要 v0.7.16 及以上。

上游组(自动切换)

几条上游组成一组,自动用最快且能通的那条,挂了自动换。

  • 上游 页 → 新增上游组,成员 至少选两条;线路的上游选这个组。
  • 每 30 秒测一次;现在用的这条只要不比最快的慢 300 毫秒以上就不换,免得来回切。切换时断开旧连接,让应用马上重连。
  • 上游页会写明每台服务器现在走的是哪一条。
  • 副机要 v0.7.16 及以上:只要建了上游组(哪怕还没有线路在用),版本更低的副机就会整份拒收同步。

巡检与告警

面板定时测试上游,出故障和恢复时可以发 Telegram。

  • 每台服务器只测自己线路用到的上游;没有线路用的标 未使用,不测也不告警。
  • 状态列可能显示 故障、待测、数据过期;点行末箭头看每台服务器的检查详情和报错。
  • 设置 → 上游巡检:巡检间隔(分钟)(0 = 关闭)、连续失败几次判定故障。
  • 概览页的 上游巡检 卡片可以点 立即巡检。

外部节点

把别处的节点(机场订阅、单条分享链接)并进你的用户订阅,排在本站节点后面。

  1. 外部节点 页 → 新增外部节点:类型选 外部订阅(一个订阅地址,定时抓取)或 分享链接(单条节点)。
  2. 填 链接 / 订阅地址;可以加 节点名前缀(如 "[中转] ")方便用户区分。保存。
  3. 到 用户 里编辑要给的人,勾上 外部节点。
  • 主机定时抓取,间隔在 设置 → 订阅 → 外部订阅刷新间隔(分钟);抓取失败时保留上次成功的内容,列表里写明错误。
  • 支持 base64 / 明文链接列表、Clash YAML、sing-box JSON。

隐藏、改名、排除关键词

机场塞的"剩余流量""官网"之类信息节点,和不想给用户的节点,都可以不输出。

  • 点 展开节点 看解析出的全部节点;勾选后点 隐藏选中 / 显示选中;单个节点可以 改名。
  • 隐藏和改名按名字 + 节点指纹(地址、端口、密码等)一起记,机场改名、调顺序后照样认得。
  • 排除关键词:名字含这些词的节点不输出,逗号分隔,如 官网,到期,剩余流量,套餐;以后新出现的也管用。名字每次刷新都会变的信息节点,用它最合适。
  • 节点暂时消失时,隐藏 / 改名记录会保留,回来照样生效;确定不要了点 清理。
  • 有副机时:隐藏和改名要求副机 v0.7.17 及以上,排除关键词要求 v0.7.16 及以上,版本更低的副机会整份拒收同步。

测速、测大陆连通、作上游

展开节点后可以直接测它们能不能用,也能把好用的节点变成上游。

  • 测速全部 / 测速选中:从每台启用的服务器真连一次测延迟,代表它作为上游时好不好用;勾 含已隐藏 连隐藏的一起测;随时可以 停止测速。显示 不支持 的是协议转不成本站出站、没法测。
  • 测大陆连通:从大陆三网测点连选中的节点,看有没有被墙;hysteria2、tuic 这类 UDP 协议只能 ping 地址;国内中转入口香港不通属正常。
  • 添加为上游:勾选节点、各起一个名字,直接变成上游(重名会报错,不会自动改名)。

证书

证书让线路、面板、订阅走 TLS / HTTPS。一台服务器可以放多张,签发后会自动续期。

添加证书

证书 页 → 添加证书,按有没有域名选 证书来源。

  • 有域名(自动签发):先到域名服务商把 A 记录解析到服务器 IP。填域名,选 验证方式:
    • HTTP(临时监听 80 端口):80 端口要空闲、公网能访问。
    • DNS(Cloudflare API):域名在 Cloudflare 上时用,填 Cloudflare API Token(要有这个域名的 DNS 编辑权限,怎么创建见 Cloudflare API 令牌怎么创建),不用开 80 端口,能自动续期。
    • DNS(手动加 TXT 记录):其它 DNS 服务商用,按页面提示加 TXT 记录,公共 DNS 查到后自动继续。
    先点 预检 DNS / 端口 看看,再点 签发证书。泛域名(*.example.com)只能用 DNS 验证。
  • 无域名(自签):点 生成自签证书;证书包含的地址(留空自动) 留空就用本机公网 IP。订阅里每个节点会自动带"允许不安全",客户端不用设置;面板和订阅建议保持 HTTP。
  • 已有证书:服务器上已经有 certbot、宝塔、nginx 或商业证书时,填 证书文件(fullchain) 和 私钥文件 的路径,点 使用该证书。
选用途在 添加后用于 里勾:设为线路默认证书、用于面板 HTTPS、用于订阅 HTTPS;没勾的用途不受影响。默认勾选:还没有正式证书时勾着 设为线路默认证书;添加的不是自签证书、而面板或订阅还没用 HTTPS 时,也会勾着后两项。勾了 用于订阅 HTTPS,订阅地址会变成 https://,要把新地址发给用户;勾了 用于面板 HTTPS,重启后面板也换成 https://。

Cloudflare API 令牌怎么创建

用 DNS(Cloudflare API) 签证书,要一个 Cloudflare API 令牌。只让它管你这个域名的 DNS,泄露了也动不了别的。

  1. 打开 Cloudflare 的令牌创建页(已预填权限),登录你的 Cloudflare 账号。权限已经填好:「区域 → 区域 → 读取」和「区域 → DNS → 编辑」,令牌名叫 m-ui。
  2. 「区域资源」改成「包括 → 特定区域 → 你的域名」,不要留「所有区域」。
  3. 点「继续以显示摘要」,再点「创建令牌」。
  4. 复制页面上显示的令牌,粘贴到 m-ui 证书页的 Cloudflare API Token。令牌只显示这一次,离开页面就看不到了,丢了只能重新创建。
链接打不开、或页面和上面说的不一样时,手动创建Cloudflare 控制台右上角头像 → 我的个人资料 → API 令牌 → 创建令牌 → 用「编辑区域 DNS」模板 → 区域资源选「包括 → 特定区域 → 你的域名」→ 继续以显示摘要 → 创建令牌。签发时如果报找不到区域(zone),给这个令牌再加一条权限「区域 → 区域 → 读取」。
常见坑
  • 权限最小化:只要上面两项权限,区域只选要用的域名。不要用「Global API Key」(全局 API 密钥),也不要给账户级的权限。
  • 令牌泄露了:到同一页把它删掉或轮转,再把新令牌填回 m-ui。
  • 主机容灾的自动改 DNS 单独填一个令牌(见 Cloudflare 自动改 DNS),照同样的步骤再建一个就行。

证书用在哪

线路默认、面板、订阅 各用各的证书,在 正在使用 卡片里换。代理面板 默认和面板共用一张;要单独用,到 设置 → 代理面板 填 证书文件 和 私钥文件 的路径(重启生效)。

  • 点每一项旁边的 更换,从证书库里挑一张,或者选 不用 HTTPS。
  • 订阅的改动立即生效(用户要换成新的 https 地址);面板的证书改了要 重启 m-ui 才生效;换线路默认证书会让数据面重启一次。
  • 某条线路要单独用一张:编辑线路 → 证书;没有这张证书的服务器继续用它自己的默认证书。

自动续期

签发的证书到期前自动续,续好后自动换上,不用重启。

  • 启动几分钟后先查一次,之后每小时查一次;进入有效期最后三分之一时开始续(90 天的证书剩 30 天时)。
  • 失败按 1、2、4 小时退避重试;第一次失败马上通知,之后每天提醒。
  • 证书库 的 自动续期 一列能看到每张证书的状态:上次续期时间、失败次数、下次重试时间。可以点 续期 立刻续,也能关掉某张的自动续期。
  • 证书出问题(续期失败、快到期、已过期、文件读不出来)时,页面顶部会出现"证书要处理"的提醒,点 查看 去处理;副机的证书也会在主机上提醒。
常见坑
  • 用 DNS(手动加 TXT 记录) 签的证书不能自动续期,每次都要重新加 TXT;想自动续,就改用 Cloudflare 验证重新签发。
  • HTTP 验证每次续期都要临时占用 80 端口,有 TCP 线路占着 80 会续期失败。
  • 域名多出一条不指向本机的 AAAA(IPv6)记录会让验证失败:改成本机的地址,或者删掉它。
  • Let's Encrypt 已经不发到期提醒邮件了:至少在主机上配好 Telegram 或 Webhook(见 通知)。
  • 已有证书 由签发它的工具(如 certbot)续期,面板只读文件,剩 14 天起提醒。

副机的证书

每台服务器各管各的证书,在各自面板的 证书 页签发、续期。

  • 证书按名字跨服务器匹配:线路选了某张证书,没有这张的服务器用它自己的默认证书;线路的证书选择框里能看到哪台有、还剩几天。
  • 副机一般不配通知:它的续期失败、快到期由主机代发提醒,主机的服务器页也会标出 证书续期失败。
  • 在副机上签正式证书时 用于面板 HTTPS 默认勾着;勾了的话,副机重启后主机要改用 https:// 的 API 地址(见 接入一台副机),不打算改就取消这一项。

用户与套餐

一个用户就是一个订阅地址,带流量、到期、设备数和限速;套餐是这些额度的模板。

新建用户

用户 页 → 新增用户,填好额度、勾上线路,保存后就有订阅地址了。

  • 用户名(即订阅地址):主面板默认用用户名当订阅地址,不能含空格和 / ? # &,全站不能重名。知道用户名就能拿到他的订阅,别用 test、user1、姓名拼音这类好猜的名字;更稳妥的是在 设置 → 订阅 关掉 用用户名作订阅地址,之后新建的用户地址是一串随机令牌(用户名只是个名称),已有的用户点 重置订阅链接 换成随机地址。
  • 用户名:只是个名称,不出现在订阅地址里(订阅地址自动生成一串随机令牌)。但不能含空格和 / ? # &,而且全站唯一:别的代理或主面板用过的名字也不能再用,建议统一加上自己的前缀。
  • 有套餐就选 所属套餐,点 按套餐填写 一键填好额度。没有就手填:流量配额 GB(0=不限)、到期日(留空=不限)、同时在线设备(0=不限)、上行限速 Mbps(0=不限)、下行限速 Mbps(0=不限)。
  • 按月清零的(月付),勾 周期重置流量,填 重置周期(天)。
  • 勾 可用线路。一条线路在几台服务器上就有几个入口,可以只给其中某台(按服务器切换分组勾选,已勾的不会丢)。
  • 外部节点:勾上的外部节点会追加到他订阅里本站节点的后面。
  • 备注:记订单号、联系方式之类。注意:没填 订阅标题(Profile-Title) 和 页面标题 时,客户端里显示的订阅名就是备注(备注也空就用用户名),不想让用户看到的内容别写进备注。
发卡、试用填 首次连接后 N 天到期(0 = 不用):用户第一次产生流量时才开始计时,不用管到期日。

流量、到期、设备数怎么算

超量或到期会自动停用并踢下线;续费、重置流量后自动恢复。

  • 流量:上传 + 下载合计;配额可以写小数(0.1 约等于 100 MB)。经过设了流量倍率的服务器时按倍率计。
  • 到期:到点自动停用。填了"首次连接后 N 天到期"就不看到期日。
  • 周期重置:每过 N 天把已用流量清零,因超量被停用的也会自动解禁。
  • 设备数:按同时在线的来源 IP 算,所有服务器合在一起算。同一个 WiFi(同一个公网 IPv4,或同一个 IPv6 /64 网段)下的几台设备算 1 台;IPv4 和 IPv6 各自对上限计数,同一台设备同时走 IPv4 和 IPv6 不会被当成两台。
  • 设备满了只拒绝新设备,已经连着的不受影响;别的设备下线约 1 分钟后名额就空出来了。
  • 被拒的连接会在概览的 最近入站连接 里标红 设备数超限被拒。
  • 限速:同一台服务器上,这个用户的全部连接共享这份带宽;他同时走几台服务器就有几份。改了马上生效。

订阅地址、二维码与临时共享

点用户名(或 详情)打开详情,订阅地址和二维码就在最上面。

  • 订阅 下面有两个地址:带 ?format=clash 的是 Clash 专用;不带 ?format= 的是通用地址,发给用户的就是它(浏览器打开是落地页,客户端来拉时按类型给格式)。点旁边的 复制。
  • 详情里的二维码是 Clash 地址,适合用 Clash 系客户端直接扫;用手机相机扫只会下载到一个配置文件,这种情况让用户打开落地页,在那里扫码或一键导入。
  • 列表里的 更多 菜单也能直接复制 Clash 订阅、链接订阅(就是通用地址)、sing-box 订阅。
  • 用户用浏览器打开自己的订阅地址,会看到落地页:用量、到期、各客户端的一键导入、二维码(见 订阅与落地页)。
  • 临时共享:用户在落地页生成给朋友用的临时地址,流量和设备都算他自己的。详情里能看到这个地址,点 收回 立即作废。
  • 地址泄露了:更多 → 重置订阅链接。地址换成新的随机令牌,全部协议凭据重新生成,旧地址立刻失效、在线设备被断开,再把新地址发给用户。
  • 详情里还能看到 在线设备(IP)(每个 IP 正在用哪条线路)、流量图和可用线路。

续费、延期与换套餐

列表的 更多 菜单(或用户详情)里,续费… 和 换套餐… 管续费、升级、降级。

  • 续费…:先 选择套餐(默认是他现在的套餐),再选方式:续费(清零流量并顺延)、延期(保留已用流量),或 只归入这个套餐(流量与到期都不动)。期数 是一次续几期(1–120),月付套餐按季、按年卖就填 3、12;单个用户时,下面会实时显示到期和配额会变成多少。用套餐续费、延期是明确的开通动作,会把 手动 停用的人也一并启用(面板会先提示)。
  • 延长 30 天:有到期日的用户一键加 30 天(还没开始计时的"首次连接后 N 天"加到 N 上);因到期停用的会恢复,手动停用的仍停着。
  • 换套餐…:换成 选新套餐,方式 三选一:
    • 立即替换:新套餐从现在开始算 N 期,旧订阅剩下的时间和流量作废。
    • 叠加:保留旧订阅剩下的时间(和一次性流量),再加 N 期;按周期重置的套餐,流量是每期额度,不叠加。已经过期的旧订阅不结转;新套餐不限期或不限量时,原来有限的到期或配额照旧保留。
    • 按价值折算:按两个套餐的 参考价(可选),把旧订阅剩下的价值折成新套餐的时长(一次性流量的套餐同时折流量),新套餐从现在开始;用户要有所属套餐、换成另一个套餐,两个都要填参考价,期数可以填 0。
  • 本周期用量:自动(立即替换和折算清零,叠加保留)、保留(接着算)、清零(从新周期开始)。
  • 对话框下方实时预览 变更前 和 变更后,标出 升级 还是 降级。到期提前、马上超量这类会让用户吃亏的影响标红,要勾 我已确认上面标红的影响,仍然执行 才能 确认换套餐。
  • 每次打开对话框都带一个防重复的编号:双击、网络重试都只会执行一次。
  • 详情里的 套餐记录 能看到最近的续费和换套餐。
接商城续费、换套餐也能用外部 API 做,而且可以先预览再执行(见 外部 API)。

套餐

套餐是额度的模板,建号、续费、批量操作都能直接套用。

  1. 套餐 页 → 新增套餐:填 名称(如 100G/月)、说明、流量(GB)、时长(天)、设备数和上下行限速。
  2. 按月清零的勾 周期重置流量;发卡、礼品卡勾 从首次连接开始计时。
  3. 线路:套用时把用户的线路换成这些;留空 = 套用时不改动用户已有的线路。
  4. 限速规则:勾上的规则对这个套餐的用户(现有的和以后套用的)都生效。
  5. 参考价(可选):只在换套餐用"按价值折算"时用,不给用户看;两个套餐填同样的价就是同价互换。
  • 套餐页显示每个套餐有多少用户。
  • 改套餐不会自动改已经套用过的用户;要让他们按新额度走,就给他们续费或换套餐。
  • 代理只看得到、也只能用自己建的套餐。

批量操作

勾选多个用户后,顶部出现批量操作条(表头的全选只勾当前这一页)。

  • 启用、停用、延期、套用套餐、重置流量、删除。
  • 批量生成:按 用户名前缀 一次建 数量 个,命名方式 选 前缀 + 随机 8 位 或 前缀 + 序号(001…,订阅地址用随机串);生成后列出每个人的订阅地址,可以整段复制。这里给的是 Clash 地址(带 ?format=clash),发给不用 Clash 的用户时,去掉末尾的 ?format=clash 就是通用地址。
  • 导出 CSV:导出用户列表,订阅那一列也是 Clash 地址。

停用原因与踢线

列表的状态一列写明为什么停用,也就决定了怎么恢复。

  • 超量、到期:续费、重置流量或延长到期后自动恢复。
  • 手动:手动停用的不会因为重置流量、延长到期或周期重置而自动恢复。但用套餐续费或延期(续费…、批量 套用套餐)和 换套餐… 是明确的开通动作,会把他一并启用:续费和批量套用套餐时,面板会先提示里面有手动停用的人、续费后会被启用。外部 API 的续费、换套餐也一样会启用。
  • 限速中:正被规则临时限速(见 规则)。
  • 踢下线:断开这个用户在所有服务器上的连接(hysteria2、TUIC、AnyTLS 整条会话一起关)。没停用的话客户端会马上重连,想彻底断就先停用。
  • 列表上方可以按 全部、启用、停用、已过期、超量 筛选。

从旧面板导入用户

线路已经在 m-ui 上建好、只想把老用户搬过来时用。

  • 用户 页点 从旧面板导入,上传旧面板的 .db 文件,点 开始导入。
  • 同名用户会被旧库的值覆盖用量、配额、到期、启停、周期重置,以及旧库里不空的备注和说明;其余的新建,沿用旧面板的用户凭据。可以勾 给新建的用户分配全部现有线路。
  • 只导入用户时,线路、入站端口、订阅端口和路径都还是 m-ui 自己的:用户要用 m-ui 的新订阅地址重新导入,停掉旧面板之前先把新地址发给大家。
  • 连线路、上游、设置一起搬,见 从旧面板迁移。

规则(临时限速)

规则给用户加临时限速:比如晚高峰全员限到 30 Mbps,或者 10 分钟内跑了 1 GB 的人限速 20 分钟。

两种规则

  • 时段限速:每周指定几天的某个时间段内限速,走出时段自动恢复。按面板时区算,结束早于开始表示跨午夜;星期 全不勾等于每天。
  • 突发限速:最近 统计窗口(分钟) 内上下行合计达到 触发流量(GB,上下行合计),就限速 限速时长(分钟);到时自动解除,再次达到再次限速。

新建规则

  1. 规则 页 → 新增规则:起个名字,选 类型,填条件。
  2. 填 上行 Mbps / 下行 Mbps,0 = 这个方向不改。
  3. 只升不降:开着(默认)时结果不会高于用户自己的限速,只会更严;关掉就直接用规则的值,可以用来在某个时段放宽。
  4. 目标 可以叠加:全部用户(含以后新建的)、某个套餐的用户、某个代理名下的全部用户、逐个勾选。
  5. 保存。
按套餐限速也可以在编辑套餐时勾 限速规则,让这个套餐的用户都跟着规则走。

生效与查看

  • 多条规则同时命中同一个用户时,取最严的一条。
  • 规则列表的 生效中 一列点 查看,看现在谁被限速、还剩多久;用户列表也会标 限速中。
  • 改动对在线连接立即生效,不用等重连;规则由主机每 10 秒判定一次,自动同步到副机。停用规则后,它造成的限速马上解除。
  • 规则限速不显示在用户的落地页上。突发限速触发时想收到通知:设置 → 通知 → 突发限速触发时通知。

代理(分销)面板

代理是帮你卖号的人:你给他线路和额度,他在自己的代理面板里建用户;他只看得到自己名下的用户和自己建的套餐。

代理面板只管你名下的用户:站长给你线路和额度,你在这里建号、续费、看用量。

开通一个代理

  1. 代理 页 → 新增代理:名称 就是代理的登录名。
  2. 勾 可用线路:代理只能把这些线路分给他的用户;可以只授权某台服务器上的入口。
  3. 填额度:流量额度 GB、用户数上限、设备池、带宽池 · 上行 Mbps / 带宽池 · 下行 Mbps、到期日(留空=不限);0 = 不限。
  4. 保存后把代理面板地址发给他:代理列表下方写着,新建成功的提示里也有(默认端口 2054、路径 /dl/)。
  • 新代理没有密码:24 小时内他用名称登录、密码留空直接点登录,进去后先设密码。过期没认领、或者忘了密码:更多 → 重置密码(会一并清掉他的两步验证和外部 API 令牌,再开 24 小时)。
  • 取消勾选某条线路,他名下的用户马上就不能用这条线路了。
  • 重置流量:把他名下所有用户的已用流量清零。
  • 代理的用户不出现在主面板的用户页里;要看就点这个代理的 详情。
  • 代理面板的端口、路径、证书在 设置 → 代理面板 里改,用不上可以关掉 启用代理面板;记得在防火墙放行 2054/tcp。

额度怎么算

  • 流量额度:按名下所有用户的全部用量算,代理自己重置流量、续费、删号都抵不掉;只有主面板的"重置流量"能清零。
  • 设备池:名下所有用户同时在线的设备总数上限(所有服务器合计)。池满只拒绝新设备,已连着的不受影响。
  • 带宽池:名下所有用户合计的速率上限,每台服务器各一份。
  • 给单个用户填多少都行,但总量受这几个池限制。
  • 到期、被停用、流量超额,任何一条踩线,名下全部用户立刻停用、订阅打不开。

第一次登录与设密码

  1. 打开站长给的代理面板地址(默认 http(s)://服务器地址:2054/dl/)。
  2. 用户名填代理名;第一次登录密码留空,直接点 登录。
  3. 按提示 设置登录密码(至少 8 位),以后用新密码登录。
常见坑新代理只有 24 小时认领时间。过期或者忘了密码,要找站长在主面板重置密码,重开 24 小时。登录后建议在 账号 页打开两步验证。

代理面板里能做什么

  • 概览:已用流量和额度、用户数、在线用户和设备。
  • 用户:新增、编辑、续费、延期、重置流量、踢线、重置订阅链接、批量操作、看用量曲线和在线设备。建号只填名称,订阅地址是随机令牌。
  • 套餐:只看得到、也只能用自己建的套餐。
  • 账号:额度、密码、两步验证、自己的订阅页文案、外部 API。
  • 只能分配站长授权的线路(授权可能只到某台服务器)。

账号页

代理面板的 账号 页管登录安全、额度,以及你的用户看到的订阅页。

  • 我的额度:已用流量、设备池(在线 / 上限,以及已分配给用户的总数)、带宽、到期、用户数。设备池满时这里会写最近拒绝了几台新设备。
  • 登录密码:改密码。
  • 两步验证(2FA):见 账号与两步验证。
  • 订阅页:你名下用户看到的订阅页文案:订阅标题(Profile-Title)(客户端里显示的名字)、页面标题、页脚联系方式、选购 / 续费链接、公告(支持换行);留空就用主面板的。也能单独关掉订阅页或临时共享。
  • 落地页 logo:上传你自己的 logo,上传即生效;没设时用主面板的。
  • 外部 API:给你自己的商城、机器人用(见 外部 API)。

订阅与落地页

订阅地址给客户端导入;同一个地址用浏览器打开,就是用户自己的落地页。

订阅地址与格式

  • 形如 http(s)://域名或IP:2056/sub/用户名(或一串随机令牌)。
  • 一个地址就够:客户端来拉时按它的类型给格式。Clash 系(Clash Verge、mihomo、Stash)拿 Clash 配置,sing-box 系(SFA、SFI 等)拿 sing-box 配置,NekoBox、v2rayN、Shadowrocket 等拿通用链接。
  • 想指定格式就在地址后面加:?format=clash(Clash)、?format=json(sing-box)、?format=mihomo(强制按新内核 Clash 给)。
  • 每条线路在每台服务器上各出一个节点,节点名后缀是服务器名;流量倍率不是 1 的服务器会带 x2 之类的标记。
  • 节点地址默认用服务器 IP(域名只作 SNI),免得客户端 DNS 被污染连不上。
  • 用户被停用、到期、用完时,客户端拉订阅会拿到 404,线路也不再放行。

用户怎么导入

  • 最简单:把通用订阅地址(不带 ?format= 的那个)发给用户,让他用手机或电脑浏览器打开,在落地页点自己客户端的一键导入,或者扫二维码。
  • 落地页一键导入按钮右上角的下载箭头,会打开各系统客户端的下载页(iOS、Android、Windows、macOS、Linux)。这一页的地址里带着本人的订阅地址(页内「← 返回订阅页」也是),不要转发;想让别人装客户端,转发各客户端的官网或发布页。
  • 也可以复制地址,粘贴到客户端的"添加订阅"里。
  • 客户端里显示的订阅名依次取 订阅标题(Profile-Title)、页面标题、用户的 备注、用户名,用第一个不空的。Shadowrocket、Clash Verge 只在添加订阅那一刻定名字,改了标题要让用户删掉重加,或者用落地页的一键导入(会把标题一起带上)。

订阅设置

在 设置 → 订阅 和 订阅格式与模板 两组里。

  • 订阅标题(Profile-Title)、更新周期(小时)。
  • 用用户名作订阅地址:默认开;关掉后新建用户的地址是随机令牌,已有用户不变。
  • 订阅允许不安全证书:默认自动(用自签证书时打开)。
  • 订阅里的节点地址:IP(推荐) 或 域名。
  • 链接订阅 base64 编码、顶部显示流量提示节点、外部订阅刷新间隔(分钟)。
  • 按客户端自动给格式:默认开;关掉后不带 ?format= 的地址一律给通用链接。
  • 自定义模板:Clash 模板(YAML,留空用内置) / sing-box 模板(JSON,留空用内置),可以先点 填入内置 Clash 模板 再照着改;节点和分组由面板填进去,写错了保存时会报错。
常见坑改了订阅的 路径 或端口,用户已有的订阅地址全部失效,要重新发给用户。

落地页

用户在浏览器里打开订阅地址看到的页面:用量、到期、一键导入、二维码,还有你的公告和联系方式。

  • 在 设置 → 订阅页 里改;代理在自己的 账号 → 订阅页 里改(留空跟主面板)。
  • 在 账号 → 订阅页 里改,留空就用主面板的。
  • 浏览器打开订阅地址时显示订阅页:关掉后浏览器也只拿到订阅内容。
  • 页面标题、页脚联系方式、公告(支持换行)。
  • 选购 / 续费链接:填了以后落地页出现"选购 / 续费"按钮(用户到期、用完、被停用时它是主按钮)。
  • 落地页底部显示 Powered by m-ui:代理的落地页不显示。
  • 落地页 logo:点 上传 / 更换,上传即生效,不用点保存。支持 PNG、JPEG、GIF、WebP、SVG,会先缩到 480×160 以内并转成 PNG(不超过 64 KB);落地页上显示高 28 像素、最宽 160,也用作浏览器标签图标。落地页跟随访客的深色模式,深色时 logo 下面垫一块浅色底,设置里的预览并排显示两种效果;透明底的白色 logo 两种都看不清。恢复默认 换回内置 logo。代理没设时用主面板的,副机随主机同步。
  • 用户用完、到期、被停用时,浏览器里仍能打开自己的落地页,顶部写明原因和找谁续费;客户端拉取则是 404。地址对不上任何用户时,浏览器显示"订阅地址无效"。

公告和联系方式里写链接

公告(支持换行) 和 页脚联系方式 里可以写可点的链接,页面上只显示文字。

这样写页面上显示
客服小王(https://t.me/xiaowang)"客服小王"可以点
[Clash/Mihomo 教程](https://example.com/a)"Clash/Mihomo 教程"可以点
官网 https://example.com地址本身变成链接
Tg: @username@username,点了打开 Telegram
WhatsApp: +34 600 000 000号码,点了打开 WhatsApp
  • 文字里带 /、冒号,或者链接里有括号时,用 [文字](链接) 的写法。方括号、圆括号半角全角都行,中文输入法打出来的 【文字】（链接） 也认。
  • 文字(链接) 的括号前可以空一格;链接文字从括号往前取,到最近的标点或上一个链接为止。
  • Telegram 的关键词认 Tg、Telegram、电报、飞机,后面跟 @用户名 或 +号码;WhatsApp 认 WhatsApp、WA、WS,后面跟 +号码;冒号中英文都行。
  • 只认 http(s)、tg、mailto、tel 链接,别的原样显示、不能点。
  • 公告最多 4000 字,联系方式最多 300 字,输入框下面显示当前字数。

临时共享

用户可以在落地页生成一条临时地址给别人用,随时收回。

  • 每人一条;对方拿到的是同一批节点、另一套凭据。流量、设备数、限速、到期都算在本人头上。
  • 取消或重新生成后,旧的共享地址立刻失效,借用的人被断开。
  • 共享地址用浏览器打开是精简版落地页,看不到本人的用量和到期。
  • 允许用户生成临时共享地址(默认开)可以整体关掉:主面板在 设置 → 订阅页,代理在 账号 → 订阅页(主面板关了,代理这边也不生效)。
  • 在用户详情里能看到他的共享地址,点 收回 立即作废。

备份与迁移

一个 zip 就是整个面板:数据库(线路、用户、流量、设置)加证书,设置里引用的数据目录外的证书文件也在里面。备份好它,换机、重装都能把数据原样恢复。

备份

  • 备份 页 → 立即备份:下载 到本地,或者 保存到服务器(在 服务器上的备份 列表里)。
  • 定时备份:每天几点(-1 关闭)(按面板时区,见 设置 → 面板 → 时区)、保留份数;可以勾 同时推送到 Telegram(先配好 Telegram 通知)。
  • 命令行:m-ui backup -db /etc/m-ui/m-ui.db -out 备份.zip,或者 m-ui 菜单 9。
常见坑备份里有全部用户凭据和证书私钥,不要发到公开的地方。

还原

  1. 备份 页 → 还原:选备份文件(zip 或 .db),点 还原。
  2. 确认后 m-ui 自动重启,替换数据库和证书。设置里引用的数据目录外的证书文件(比如 已有证书、从旧面板导入的证书路径)会还原到 /etc/m-ui/ 下并改好路径;证书文件万一缺了,面板和订阅先临时用自签证书启动并告警,不会起不来。
  3. 原来的库保留为 .bak-* 文件,只留最近两份:连着还原几次,最早那份会被删掉。拿不准该用哪份备份时,先点 立即备份 把当前的库下载下来再试。
  • 新机器可以在安装时一步装好并还原(命令见下面的 换服务器)。
  • 服务停着时也能用命令行还原:m-ui restore -db /etc/m-ui/m-ui.db -from 备份.zip。

换服务器

备份 页的 换机向导 用备份分四步把整个面板搬到新服务器。订阅用的是域名时,端口、凭据、订阅地址都不变,把域名解析改到新机,用户就跟过来了。

旧主机还在运行时,优先用「设为主机」新机装好 m-ui、像副机一样接入(见 接入一台副机),同步上以后在 服务器 页对它点 设为主机:数据一次交接过去,不用备份、还原,旧主机自动变为副机(见 设为主机)。下面的四步留给旧主机已经不在、只能靠备份的时候。
  1. 把备份 zip 传到新机,执行 bash <(curl -fsSL https://raw.githubusercontent.com/Maoyangui/m-ui/main/deploy/install.sh) --restore /root/m-ui-20261111-030000.zip(换成你的文件路径;amd64、arm64 都是这一条,脚本先装最新版再还原,证书一起还原)。向导里也有这条命令。
  2. 用新机 IP 打开面板(端口和路径同旧机),确认线路在运行;有副机的话,新主机会自动重新连上它们。
  3. 到 DNS 服务商把域名解析改到新机 IP,用向导里的 检查解析 看主流解析器是否都已生效。
  4. 新机上用户都正常后,在旧机上执行 systemctl disable --now m-ui(停掉并取消开机自启),或者用 m-ui 菜单 14 卸载。只 systemctl stop 不够:旧机和新机是同一份数据、同一套副机令牌和 Telegram 机器人,旧 VPS 一重启(比如服务商维护)它就会自己起来,拿过期的数据继续服务、给副机推送、发通知。
常见坑
  • 订阅地址里是 IP(没给订阅配域名)时,换机后订阅地址和主机上的节点地址都会变成新机的 IP,第 3 步也用不上:先给订阅配一个域名、把新地址发给用户一次再换机;或者换机后把新订阅地址发给所有用户,等大部分人换好再停旧机。
  • 新机的安全组和防火墙要放行和旧机一样的端口:面板、订阅、代理面板、每条线路(Hysteria2、TUIC 和端口跳跃的范围要放 UDP)。
  • WARP 是装在系统里的,不在备份里:线路上游用了 warp 的,先在新机 运维 页安装并启用 WARP(端口和旧机一样)。
  • 副机的面板端口只对旧主机 IP 放行的,先把新主机的 IP 加进去,不然新主机连不上副机。
  • 两台同时运行期间不要在旧面板上做任何改动,同时运行的时间越短越好。
只换副机更简单新副机装好后,在主机 服务器 页把那一行的 API 地址和令牌换成新的,主机会自动重新推送。

从旧面板迁移

  • 整机迁移(线路、上游、用户、设置都带过来):在新服务器上安装时加参数,bash <(curl -fsSL https://raw.githubusercontent.com/Maoyangui/m-ui/main/deploy/install.sh) --import /path/to/旧面板.db。入站端口、用户凭据、面板路径和订阅路径都保留;但订阅端口会改成 2056,单独的订阅域名也不会带过来:旧面板的订阅不在 2056 端口的,装好后用 m-ui 菜单 6 把订阅端口改回原来的;有单独订阅域名的,用 m-ui set -db /etc/m-ui/m-ui.db subDomain=域名 补上。这两项都对上了,客户端才不用改。
  • 只搬用户:用户 页 从旧面板导入(见 从旧面板导入用户)。

通知(Telegram)

用 Telegram(或 Webhook)收告警:用户到期、上游故障、证书续期失败、服务器被墙……还能在手机上用机器人管用户。

配置 Telegram 通知

  1. 在 Telegram 里找 @BotFather 创建一个机器人,拿到 Token(形如 123456:ABC-DEF…)。
  2. 给 @userinfobot 发条消息,拿到你的 Chat ID(群和频道的 ID 是负数)。再给你自己的机器人发一条消息,它才能主动给你发。
  3. 设置 → 通知:勾 启用 Telegram 通知,填 Bot Token 和 Chat ID,点 保存。
  4. 点 发送测试消息,手机收到就好了。
常见坑服务器连不上 Telegram(比如国内机器)时,在 代理(可选) 填一个代理;装了 WARP 就填 socks5://127.0.0.1:40000。

发哪些通知

在 通知 这一组里逐项勾选;Telegram 和 Webhook 共用这些开关。

  • 面板登录 / 连续登录失败
  • 用户被自动禁用(到期/超量)、用户即将到期(提前天数在 到期前几天提醒)、用户流量告急(比例在 用量达到百分比时提醒)
  • 突发限速触发时通知
  • 上游故障 / 恢复、数据面停止 / 恢复
  • 大陆连通异常 / 恢复
  • 证书签发 / 续期 / 到期提醒(副机证书的也由主机发)
  • 每日报告,几点发在 每日报告时间(小时,0–23,按面板时区)
  • 主机容灾:备用发现主机失联、等你回复确认码接任、接任完成、设为主机做完或没做成、原主机回来变为副机时,也会发通知(见 设为主机与主机容灾)。

Webhook

想把告警接到自己的系统里(企业微信、钉钉中转、工单……),用 Webhook。

  • Webhook 地址:勾选的事件也会 POST 到这里,JSON 里有 event、text、time。留空就不发。
  • Webhook 密钥:填了就带 X-M-UI-Signature 头(sha256= 正文的 HMAC),对方可以验证真伪。

运维、日志与更新

服务器调优、查日志、排查连接、升级版本,都不用回终端。

系统优化

运维 页的 系统优化:swap、文件句柄上限、时间同步、内核参数和 BBR,一般 VPS 用默认值就行。

  • 点 一键优化 全做一遍,也可以逐项改参数后点 执行;任务输出实时显示在 任务输出 里。
  • 同一页还能限制系统日志(journald)的占用和保留天数:它装的是整台机器所有服务的日志,限制它不影响面板。
  • WARP 也在这一页(见 WARP)。运维任务只在 Linux 上、m-ui 以 root 运行时可用。

日志

日志 页有三类:订阅访问、核心日志、操作审计。

  • 订阅访问:谁、从哪个 IP、用什么客户端拉了订阅。
  • 核心日志:数据面和面板的运行日志。面板里这份只存在内存里(最多约 1 万条,重启就清);同样的内容也会写进系统日志(journalctl -u m-ui 能看到),清空 只清面板里这一份,系统日志的占用和保留天数在 运维 页限制。记录日志 可以关掉省资源。
  • 数据面级别:默认 warn,只记警告和错误;排障时临时调到 info 或 debug,改了立即生效,查完记得改回 warn(info 一小时就几万行,会拖慢磁盘)。
  • 操作审计:谁在什么时候做了什么(面板、外部 API、Telegram 机器人的操作都在)。
  • 订阅访问和操作审计可以设 自动清理(保留 1 天、1 周、1 个月或不清理);每类都能 清空。

最近入站连接

概览页底部的 最近入站连接 用来排查"用户说连不上":看他的 IP 有没有连到服务器、连的哪条线路。

  • 记录的是通过了协议握手和认证的连接,带用户、线路、服务器、次数和最近时间。
  • 被设备数上限或代理设备池拒绝的连接也会列出来并标红:设备数超限被拒、代理设备池已满被拒。
  • 握手或认证失败的连接(证书、密码、SNI 不对)也会列出,并写明失败原因。
  • 列表里没有某个 IP,多半是包没到服务器(安全组、防火墙、客户端网络)。要确认包到没到:TCP 线路可以到日志页把 数据面级别 临时调到 info,看有没有 inbound connection from。Hysteria2、TUIC 这类 UDP 线路只有握手和认证都成功后才记这一行(密码、SNI 不对时什么也不记),看不到不代表包没到,要在服务器上抓包确认,比如 tcpdump -ni any udp port 端口。

更新

有新版本时,左下角版本号旁会出现箭头,点它就能一键更新。

  • 点箭头 → 立即更新:校验下载的程序后替换并重启,十几秒后面板自动刷新;用户、线路、订阅地址和证书都不变,这台机器上的连接会断一下。
  • 新版本起不来会自动换回旧版本,页面顶部会说明;点 知道了 关掉提示。
  • 副机也是完整安装,在各自的面板里更新;主副机版本要保持一致。
  • 也可以 SSH 执行 m-ui 选菜单 10。它和面板的更新箭头一样,直连 GitHub 不通时会自动经本机的 WARP 再试,所以纯 IPv6 机器(连不上 GitHub)装好 WARP 就能更新。重新执行一键安装脚本也能更新,但脚本不会自己走 WARP:纯 IPv6 机器要先执行 export ALL_PROXY=socks5h://127.0.0.1:40000(端口按 WARP 的设置),或者手动上传安装包。

命令行与 SSH 菜单

面板打不开、忘了密码时,在服务器上执行 m-ui 用数字菜单。

  • 菜单:1 查看面板地址 / 账号、2 重启、3 停止、4 启动、5 重置管理员密码、6 修改面板端口 / 路径 / 订阅端口、7 重置全部设置、8 查看最近日志、9 立即备份、10 更新到最新版、11 生成自签证书、12 切换主机 / 副机角色、13 关闭两步验证、14 卸载。
  • m-ui info:打印面板地址、路径和账号状态。
  • m-ui passwd:重置管理员密码(同时关掉两步验证)。
  • m-ui set -db /etc/m-ui/m-ui.db 键=值:直接改设置,比如 webPort=3053。
  • m-ui render:打印并校验当前的 sing-box 配置。
  • 菜单 15 和 m-ui ha status / takeover / set-master / pause / resume:主机容灾与设为主机(见 命令行)。
  • 数据在 /etc/m-ui/:m-ui.db(数据库)、cert/(证书)、backups/(定时备份)。

外部 API

给商城、计费系统、机器人用:凭一个令牌就能建号、续费、换套餐、启停、取订阅地址,不用登录面板。

开启与令牌

  1. 管理员 页 → 外部 API:打开卡片右上角的开关(鼠标停上去写着 开启 / 关闭外部 API),复制 接口前缀 和 令牌。
  2. 账号 页 → 外部 API:打开卡片右上角的开关(鼠标停上去写着 开启外部 API),复制 接口前缀 和 令牌。
  3. 每个请求带上令牌:请求头 Authorization: Bearer 令牌(或 X-API-Key: 令牌),请求体用 JSON。
  4. 开启后令牌下面有 接口一览(每个接口的说明)和 示例(curl)(已经填好你的接口前缀和令牌),可以直接照抄;没开时接口一览折叠着,也能先看。
常见坑
  • 令牌等于你在面板里的全部权限,只放在服务端程序里,不要写进网页或客户端。泄露了就点 重新生成,旧令牌立刻失效。
  • 接口只在主服务器上调用;副机上的写操作会被拒绝。
  • 代理的令牌只能动你名下的用户、你自己的套餐和站长授权给你的线路;代理被停用、到期或被重置密码后,令牌立刻失效。

先预览、防重复、降级确认

续费和换套餐会动用户的钱和时间,接口提供了三道保险。

  • 预览:请求里带 "dryRun": true 只计算不执行,返回变更前后的对比,商城可以拿来报价。
  • 防重复(幂等):带 requestId(或请求头 Idempotency-Key,比如用订单号),同一个编号重试只执行一次,不会重复加时。
  • 降级确认:换套餐会让用户马上超量、或到期提前时,接口返回 409 和完整预览,确认后带 "force": true 再调一次才执行。
  • 面板的接口一览里标着 幂等、可预览 的接口支持这些。
  • 续费、换套餐是明确的开通动作:被手动停用的用户也会被启用,要先停掉的人别拿去续费。

安全

改掉默认密码、打开两步验证、藏好面板地址,就挡住了绝大多数风险。

账号与两步验证

  • 改密码、改用户名:管理员 页的 登录账号。
  • 改密码:账号 页的 登录密码。
  • 两步验证(2FA):点 生成密钥,用认证器 App(Google Authenticator、Microsoft Authenticator、Authy、1Password 等)扫二维码,填 App 上的 6 位码,点 验证并开启。开启后登录要密码 + 6 位码。
  • 手机丢了进不去:SSH 执行 m-ui,菜单 13 关闭两步验证;菜单 5 重置密码也会一起关掉。
  • 手机丢了或忘了密码:找站长在主面板重置密码(两步验证会一起清掉)。

面板地址与端口

  • 把默认的端口和路径改掉:设置 → 面板 → 端口 / 路径。只打开 IP:端口/ 永远是 404,别人扫到端口也看不出这是面板。
  • 面板走 HTTPS:证书页添加证书时勾 用于面板 HTTPS(重启后生效)。
  • 防火墙只放必要的端口;副机的面板端口只对主机 IP 放行(换了主机记得把新主机的 IP 加进去)。这只防得住外面的人,防不住经代理连进来的用户,见下一节。
  • 登录保护:同一来源 10 分钟内输错 10 次,先挡 5 分钟;连续输错 5 次可以发 Telegram 提醒(面板登录 / 连续登录失败)。

数据面的安全开关

  • 允许用户访问内网 / 本机地址:默认关,用户经代理碰不到只监听 127.0.0.1 的服务(比如 WARP 端口)和你的内网。确实要给用户访问内网服务时再打开。
  • 面板端口不在此列:用户经代理照样能打开 服务器公网IP:面板端口,而且这类流量走本机回环,防火墙的 IP 白名单拦不住。所以别只靠白名单保护面板:改掉默认的端口和路径,用强密码,打开两步验证。
  • 屏蔽 BT 下载:拒绝经代理的 BT 连接,免得 VPS 招来版权投诉。
  • 副机的 API 地址用 HTTPS,否则同步时令牌和用户凭据走明文。
  • 备份 zip 里有用户凭据和证书私钥;外部 API 令牌等于管理员权限:都要妥善保管。

常见问题 / 排错

先按症状找;没找到就用上面的搜索框搜关键词。

连不上

订阅能刷新,但节点连不上?
先让用户刷新一次订阅,再按顺序查:线路端口有没有在安全组 / 防火墙放行(Hysteria2、TUIC 要放 UDP);用户是否被停用(看状态一列);设备数是不是满了。概览的 最近入站连接 能看到他的 IP 有没有连到服务器。
提示设备数超限 / 有的设备连不上?
同时在线的设备(按来源 IP 算,所有服务器合计)到了上限,新设备会被拒绝。等别的设备下线约 1 分钟,或者调高设备数。手机切换 WiFi 和流量会换 IP,短时间内可能算两台。
IPv6 的节点不通?
多半是云安全组没给 ::/0 放行(TCP、UDP 分开加),或者系统的 ip6tables / ufw 拦着;再确认用户自己的网络有 IPv6。WARP、NAT 之类只能出站的 IPv6 不能给用户连。服务器页的 IPv6 入站检测能直接告诉你通不通。
某个地区突然全连不上?
到 服务器 页点 检测大陆连通:IP 被墙 要换 IP,端口被封 换个端口就行。

面板与服务器

打开 IP:2053/ 是 404?
故意的:根路径不跳转,免得把面板路径告诉扫端口的人。打开完整地址,比如 http://IP:2053/app/。忘了路径就 SSH 执行 m-ui 选菜单 1。
忘记密码 / 手机丢了进不去?
SSH 执行 m-ui:菜单 5 重置管理员密码(同时关闭两步验证),或者菜单 13 只关闭两步验证。
改了端口、监听地址、证书不生效?
这些要重启 m-ui:设置页页头的 重启 m-ui,或菜单 2。改路径保存就生效。
副机显示离线?
看服务器页写的原因,对照 离线排查。用自签证书的副机要勾 跳过证书校验;重签过副机证书要点 重置指纹。
证书续期失败?
看证书库 自动续期 一列的原因:HTTP 验证要 80 端口空闲;手动 DNS 的证书不能自动续;域名多了指向别处的 AAAA 记录也会失败。见 自动续期。
WARP 启用失败?
看运维页的任务输出。常见原因:40000 端口被占用,换个 SOCKS5 端口 再启用;系统不是 Ubuntu / Debian,一键安装不支持,要自己装(见 WARP)。
订阅返回 429?
同一个 IP 每分钟拉订阅超过 120 次被限流了,一般是客户端更新太频繁。这个限流也是防别人猜用户名批量拿订阅的主要手段,别关掉;确实需要就调大(比如 600):m-ui set -db /etc/m-ui/m-ui.db subRateLimit=600,同时建议关掉 用用户名作订阅地址,让新用户用随机令牌。

订阅与用户

客户端里订阅名不对?
到 设置 → 订阅 填 订阅标题(Profile-Title)(代理在自己账号页的订阅页里填);没填时依次用页面标题、用户备注、用户名。到 账号 → 订阅页 填 订阅标题(Profile-Title);没填时依次用页面标题、用户备注、用户名。Shadowrocket、Clash Verge 只在添加订阅时定名字,要让用户删掉重加,或者用落地页的一键导入。
用户用完、到期后看到什么?
浏览器打开订阅地址仍是他的落地页,顶部写明原因、联系方式和续费按钮(如果填了选购链接);客户端拉订阅拿到 404。续费或重置流量后马上恢复。
订阅地址泄露了?
用户的 更多 → 重置订阅链接,旧地址和凭据立刻失效,把新地址发给用户。
代理登录不上?
新代理第一次登录密码留空;24 小时认领时间过了、或忘了密码,要站长在主面板 代理 页 更多 → 重置密码。
